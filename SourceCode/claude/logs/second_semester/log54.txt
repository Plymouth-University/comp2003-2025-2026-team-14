  VALID_LOBBY_CODE_CHARS

  - Sets caret position to the clicked field index (clamped to current text
  length)

   input fields
  - Added validation warning for lobbyCodeVisualFields count

  with validation
  - OnLobbyCodeInputFieldChanged(): Marked as deprecated with no-op
  implementation
  - Header comment: Updated to indicate lobbyCodeInputFields is deprecated

  5. Added Required Namespace

  - Added using System.Text; for StringBuilder usage

  Key Implementation Details

  - Character Validation: Uses the existing VALID_LOBBY_CODE_CHARS constant
  (excludes ambiguous characters like 0/O/1/I)
  - Visual Field Updates: Each of the 6 lobbyCodeVisualFields displays one
  character from the hidden input field
  - Caret Positioning: When clicking a visual field, the caret is placed at
  the corresponding position in the hidden input field
  - Backward Compatibility: The old lobbyCodeInputFields field is marked as
  deprecated but kept for serialization compatibility
