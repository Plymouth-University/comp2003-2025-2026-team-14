       433 +  
       434 +  1. **Open the Lobby Scene**:
       435 +     - Open `Assets/Scenes/LobbyScene.unity`
       436 +     - Ensure the scene contains the required UI elements:
       437 +       - Room code display (TextMeshProUGUI)
       438 +       - Max players display (TextMeshProUGUI)
       439 +       - Turn time limit display (TextMeshProUGUI)
       440 +       - Host name display (TextMeshProUGUI)
       441 +       - Start Game button (Button)
       442 +       - Eight player list panels (GameObject) with child 
           + Text components for player names
       443 +       - Seven kick buttons (Buttons) for players 2-8 
           + (optional)
       444 +  
       445 +  2. **Add LobbyUIManager Component**:
       446 +     - Select the main UI Canvas or a dedicated GameObject 
           + for lobby management
       447 +     - Add the `LobbyUIManager` component via Add Component >
           +  Scripts > LobbyUIManager
       448 +  
       449 +  3. **Assign Manager References** (optional, can be 
           + auto-filled):
       450 +     - `FirebaseManager`: Leave empty, script will find 
           + singleton instance
       451 +     - `MultiplayerManager`: Leave empty, script will find 
           + singleton instance
       452 +     - `LobbyManager`: Leave empty, script will find on 
           + MultiplayerManager's GameObject
       453 +     - `SyncManager`: Leave empty, script will find singleton
           +  instance
       454 +  
       455 +  4. **Assign UI Element References**:
       456 +     - `Room Code Text`: Drag the TextMeshProUGUI element 
           + displaying room code
       457 +     - `Max Players Text`: Drag the TextMeshProUGUI element 
           + displaying max players
       458 +     - `Turn Time Text`: Drag the TextMeshProUGUI element 
           + displaying turn time limit
       459 +     - `Host Name Text`: Drag the TextMeshProUGUI element 
           + displaying host name
       460 +     - `Start Game Button`: Drag the Button for starting the 
           + game
       461 +  
       462 +  5. **Assign Player List UI Arrays**:
       463 +     - `Player List Panels`: Assign the eight GameObjects 
           + representing each player slot (in order: player 1 to player 
           + 8)
       464 +     - `Player Name Texts`: Assign the eight Text components 
           + (UnityEngine.UI.Text) for player names (in same order)
       465 +     - `Player Kick Buttons`: Assign the seven Buttons for

           + implemented)
       466 +

       469 +     - For each Kick button, the script will dynamically

       470 +     - Add a Leave Lobby button elsewhere and connect to
