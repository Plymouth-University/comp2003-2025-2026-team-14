  Original Problem:

  events but missed OnTurnCompletionReceived:

  // Original (incomplete):
  SyncManager.OnPlacementActionReceived -= OnOpponentPlacementAction;
  SyncManager.OnDiceRollReceived -= OnOpponentDiceRollReceived;
  SyncManager.OnPlayerGameStateReceived -= OnOpponentGameStateReceived;
  // MISSING: SyncManager.OnTurnCompletionReceived -= 
  OnOpponentTurnCompletionReceived;

  Why This Caused Issues:

  1. Accumulation of Stale Event Handlers: When GameManager was
  destroyed/recreated (e.g., scene reloads), the old handler remained
  subscribed to SyncManager's event.
  2. Potential "Ghost" Subscriptions: The Unity event system might have
  maintained references to destroyed objects, causing null references or
  silent failures.
  3. Scene Transition Issues: Without re-subscription in
  RefreshManagerReferences(), new GameManager instances might not receive
  events after scene loads.
