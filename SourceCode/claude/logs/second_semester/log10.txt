       353 +  ## Auto-End Detection Implementation (2026-04-15)
       354 +  
       355 +  Auto-end detection has been implemented to automatically 
           + check for valid placements at the start of each turn (after 
           + dice roll, before player selection). When no valid 
           + placements exist, the system will prompt the player to use a
           +  wildcard (if available) or end the game.

       359 +  1. **AutoEndDetector.cs**

       360 +     - Contains algorithm to check if any valid placement 
           + exists for current dice pool
       361 +     - Checks positions adjacent to existing shapes (or river
           +  tiles if water die present)
       362 +     - Uses dummy shape for validation to avoid 
           + creating/destroying GameObjects
       363 +
