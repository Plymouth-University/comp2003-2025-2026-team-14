       424 +  ### ShapeData Asset Loading
       425 +  
       426 +  ShapeData ScriptableObjects are required for auto-end 
           + detection validation. The following steps have been taken to
           +  ensure ShapeData is available:
       427 +  
       428 +  1. **Existing Assets**: ShapeData assets already exist in 
           + `Assets/ScriptableObjects/` (TShape.asset, LShape.asset, 
           + SquareShape.asset, LineShape.asset, ZShape.asset, 
           + SingleShape.asset).
       429 +  
       430 +  2. **Resources Copy**: Assets have been copied to 
           + `Assets/Resources/ScriptableObjects/` for runtime loading.
       431 +  
       432 +  3. **Automatic Loading**: 
           + `ShapeManager.LoadShapeDataFromResources()` automatically 
           + loads ShapeData assets if serialized fields are not assigned
           +  in the Inspector. This runs in `Start()`.
       433 +  
       434 +  4. **Manual Assignment (Recommended)**: For better 
           + performance and reliability, assign ShapeData assets to the 
           + ShapeManager component in the Inspector:
       435 +     - Select the ShapeManager GameObject in the Game scene
       436 +     - In the Inspector, locate the "Shape Data Assets" 
           + section
       437 +     - Drag and drop each ShapeData asset from 
           + `Assets/ScriptableObjects/` to the corresponding field 
           + (TShapeData, LShapeData, etc.)
       438 +  
       439 +  5. **Validation**: If ShapeData is missing, auto-end 
           + detection will log warnings and skip those shapes, which may
           +  cause false positives for game end detection. Ensure all 
           + ShapeData fields are properly assigned.
       440 +  
       441    ### Known Limitations & Edge Cases
       442    
       443    - Performance: The algorithm checks all adjacent positions 
             for each shape type (6 shapes × up to ~36 positions × 8 
             rotations/flips). Optimizations may be needed for very large
              boards, but the 10×10 grid should be fine.
