  How It Works

  1. Host Experience:
    - Automatically set to ready state
    - Sees Start Game button (interactable only when all players are ready)
    - Does not see the Ready button
  2. Non-Host Player Experience:
    - Sees Ready button with text "Ready up"
    - Clicking toggles ready state and updates button text to "Unready"
    - Clicking again toggles back to unready with text "Ready up"
    - Checkmark image for their position updates for all players
  3. Multiplayer Synchronization:
    - Ready states are stored in Firebase via
  LobbyManager.UpdatePlayerReadyState()
    - All players see updated checkmark images when any player changes ready
   state
    - Start Game button becomes interactable for host only when all players
  are ready
